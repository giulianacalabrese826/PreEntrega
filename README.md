# Landing Page - Empresa de Autos
- Descripción

Este proyecto consiste en el desarrollo de una Landing Page para una empresa de autos.
La página presenta de forma sencilla y visual la información principal de la empresa y sus vehículos.

El proyecto fue realizado como parte de un curso para poner en práctica los conocimientos adquiridos en HTML, y CSS.

## Tecnologías utilizadas
HTML5 — Para crear la estructura y el contenido de la página.
CSS3 — Para personalizar los estilos, colores, tamaños y diseño.
